### Структура

>my_flask_server/
│
├── app.py                 # Главный файл приложения
├── config.py              # Конфигурация
├── requirements.txt       # Зависимости
│
├── static/               # Статические файлы
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── main.js
│   └── images/
│

│   ├── base.html
│   ├── index.html
│   ├── search.html
│   └── about.html
│
└── routes/              # Маршруты (роуты)

    ├── main_routes.py
    └── search_routes.py
  

### Кто за что отвечает?

#### 📁 **/**

`app.py` - Главный запускаемый файл
Назначение: Точка входа в приложение, инициализирует и запускает Flask сервер
- Создает экземпляр Flask приложения
- Настраивает пути к шаблонам и статическим файлам
- Регистрирует все модули (Blueprint'ы)
- Запускает веб-сервер 

`config.py` - Файл конфигурации
Назначение: Хранит все настройки приложения в одном месте
- Настройки базы данных
- Секретные ключи
- Параметры отладки
- Конфигурация поиска

 `requirements.txt` - Файл зависимостей
Назначение: Список всех Python пакетов, необходимых для работы приложения
- Упрощает установку зависимостей: `pip install -r requirements.txt`
- Обеспечивает одинаковое окружение на разных машинах

#### 📁 **templates/**
`base.html` - Базовый шаблон
Назначение: Основной каркас всех страниц, избегает дублирования кода
- Содержит общую структуру HTML (head, header, footer)
- Определяет блоки для переопределения (content, title)
- Подключает CSS и JavaScript файлы

 `index.html` - Главная страница
Назначение: Домашняя страница с приветствием и формой поиска
- Представляет сайт пользователям
- Содержит основную поисковую форму
- Навигация по сайту

`search.html` - Страница результатов
Назначение: Отображает результаты поиска и позволяет уточнять запросы
- Показывает поисковый запрос пользователя
- Отображает найденные результаты (пока заглушки)
- Форма для нового поиска

`about.html` - Страница "О проекте"
Назначение: Информационная страница о проекте и его возможностях
- Описание функционала
- Контактная информация
- Описание технологии

#### 📁 **static/**
`css/style.css` - Таблицы стилей
Назначение: Определяет внешний вид и оформление сайта
- Цвета, шрифты, отступы
- Адаптивный дизайн для разных устройств
- Анимации и эффекты
- Расположение элементов на странице

`js/main.js` - Клиентский JavaScript
Назначение: Добавляет интерактивность на стороне клиента
- Анимации элементов
- Валидация форм
- Динамическое обновление контента
- UX улучшения (подсказки, автозаполнение)

📁 **routes/**

`__init__.py` - Инициализатор пакета
Назначение: Превращает папку в Python пакет
- Позволяет импортировать модули из папки routes
- Может содержать общую логику для всех маршрутов

`main_routes.py` - Основные маршруты
Назначение: Обрабатывает основные страницы сайта
- Главная страница (`/`)
- Страница "О проекте" (`/about`)
- Другие информационные страницы

`search_routes.py` - Поисковые маршруты
Назначение: Обрабатывает всё, связанное с поиском
- Страница поиска (`/search`)  
- Обработка поисковых запросов
- Фильтрация и пагинация результатов

### Взаимодействие
```text
Пользователь
     ↓
Браузер (запрос URL)
     ↓
app.py (находит подходящий маршрут)
     ↓
routes/ (обрабатывает запрос)
     ↓
templates/ (генерирует HTML)
     ↓
static/ (добавляет стили и скрипты)
     ↓
Браузер (отображает страницу)
```
