Современное веб-приложение для поиска мест и социальных взаимодействий с полной системой аутентификации и друзей.

## 🚀 Возможности

### 🔍 Поиск
- Интеллектуальный поиск мест по различным критериям
- Поиск пользователей по имени
- Современный интерфейс с градиентным дизайном
- Адаптивный дизайн для мобильных устройств

### 👥 Социальные функции
- **Система друзей** - добавление в друзья, принятие/отклонение заявок
- **Поиск пользователей** - находите других участников
- **Управление друзьями** - просмотр списка друзей, удаление
- **Уведомления** - входящие и исходящие заявки в друзья

### 🔐 Аутентификация и безопасность
- **Регистрация** новых пользователей с валидацией
- **Вход в систему** с защитой сессий
- **Безопасное хранение** паролей (хэширование)
- **Персональные профили** пользователей
- **Защита маршрутов** - только для авторизованных пользователей

### 🎨 Интерфейс
- Современный градиентный дизайн с CSS-переменными
- Плавные анимации и переходы
- Полная адаптивность под мобильные устройства
- Интуитивно понятная навигация
- Система уведомлений и статусов
- **Модульная архитектура CSS** - легко поддерживать и развивать

## 🛠 Технологический стек

### Backend
- **Flask** - веб-фреймворк
- **Flask-Login** - управление аутентификацией и сессиями
- **Flask-SQLAlchemy** - ORM для работы с базой данных
- **Flask-WTF** - формы и CSRF защита
- **Flask-Migrate** - миграции базы данных
- **Werkzeug** - хэширование паролей и безопасность

### Frontend
- **HTML5** - семантическая разметка страниц
- **CSS3** - современные стили (Grid, Flexbox, CSS Variables)
- **Модульная архитектура CSS** - 8 специализированных файлов
- **JavaScript** - клиентская интерактивность
- **Jinja2** - шаблонизация серверной части

### База данных
- **SQLite** - для разработки (легко перейти на PostgreSQL)
- **SQLAlchemy** - ORM с защитой от SQL-инъекций

## 🚀 Установка и запуск

### 1. Клонирование и настройка

```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt

# Или установите по отдельности:
pip install flask flask-sqlalchemy flask-login flask-wtf
```

### 3. Настройка окружения

```bash
# Скопируйте пример конфигурации
cp .env.example .env

# Отредактируйте .env файл при необходимости
```

### 4. Инициализация базы данных

```bash
# Инициализация миграций
flask db init

# Создание миграции
flask db migrate -m "Initial migration"

# Применение миграций
flask db upgrade
```

### 5. Запуск приложения

```bash
python run.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Использование системы аутентификации

### Регистрация нового пользователя

1. Перейдите на `/register`
2. Заполните форму:
    - Имя пользователя (уникальное)
    - Email (уникальный)
    - Пароль (не менее 6 символов)
3. Нажмите "Зарегистрироваться"

### Вход в систему
1. Перейдите на `/login`
2. Введите email и пароль
3. Опционально: отметьте "Запомнить меня"
4. Нажмите "Войти"

### Система друзей
1. Поиск пользователей - /search-users?query=имя
2. Отправка заявки - кнопка "Добавить в друзья"
3. Принятие заявок - в разделе "Входящие заявки"
4. Управление друзьями - просмотр и удаление в списке друзей

### Доступные маршруты
#### Публичные (доступны всем)
- `GET /` - главная страница
- `GET /about` - о проекте
- `GET /search` - поиск мест
- `GET /login` - вход в систему
- `GET /register` - регистрация
#### Защищенные (только для авторизованных)
- `GET /profile` - профиль пользователя
- `GET /logout` - выход из системы
- `GET /friends` - список друзей
- `GET /search-users` - поиск пользователей
- `GET /send-friend-request/<user_id>` - отправить заявку в друзья
- `GET /accept-friend-request/<request_id>` - принять заявку
- `GET /reject-friend-request/<request_id>` - отклонить заявку
- `GET /remove-friend/<friend_id>` - удалить из друзей

## Безопасность
### Реализованные меры защиты:
#### 🔒 Аутентификация и авторизация
- Flask-Link управление сессиями
- Хеширование паролей (Werkzeug)
- Защита маршрутов @login_required
- user_loader для загрузки пользователей

#### 🛡️ Защита от веб-атак
- CSRF защита (Flask-WTF)
- XSS защита (markupsafe.escape)
- Валидация входных данных (WTForms)
- SQL-инъекции защита (SQLAlchemy ORM)

#### 📊 Безопасность данных
- Валидация уникальности в БД
- Параметризованные SQL запросы
- Защита целостности данных

#### ⚙️ Конфигурация безопасности
- SECRET_KEY для подписи сессий
- Защита сессий (SESSION_PROTECTION)
- Ограничение времени жизни сессии
- Переменные окружения для секретов

#### 🚫 Контроль доступа
- Проверка прав доступа к данным
- Авторизация на уровне бизнес-логики
- Предотвращение доступа к чужим данным
