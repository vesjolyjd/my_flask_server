# 🗺️ Mind Roadmap - Умный поиск мест

![Python](https://img.shields.io/badge/Python-3.8+-blue)

Современное веб-приложение для поиска и сохранения интересных мест с системой аутентификации пользователей.

## 🚀 Возможности

### 🔍 Поиск
- Интеллектуальный поиск мест по различным критериям
- Современный интерфейс с градиентным дизайном
- Адаптивный дизайн для мобильных устройств

### 👤 Аутентификация
- **Регистрация** новых пользователей
- **Вход** в систему с защитой сессий
- **Безопасное** хранение паролей (хэширование)
- **Персональные** профили пользователей

### 🎨 Интерфейс
- Современный градиентный дизайн
- Плавные анимации и переходы
- Полная адаптивность под мобильные устройства
- Интуитивно понятная навигация

## 🛠 Технологический стек

### Backend
- **Flask** - веб-фреймворк
- **Flask-Login** - управление аутентификацией
- **Flask-SQLAlchemy** - работа с базой данных
- **Flask-WTF** - формы и валидация
- **Werkzeug** - хэширование паролей

### Frontend
- **HTML5** - разметка страниц
- **CSS3** - стили и анимации (CSS Grid, Flexbox)
- **JavaScript** - интерактивность
- **Jinja2** - шаблонизация

### База данных
- **SQLite** - для разработки (легко перейти на PostgreSQL)

## 🚀 Установка и запуск

### 1. Клонирование и настройка

```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt

# Или установите по отдельности:
pip install flask flask-sqlalchemy flask-login flask-wtf
```

### 3. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Использование системы аутентификации

### Регистрация нового пользователя

1. Перейдите на `/register`
2. Заполните форму:
    - Имя пользователя (уникальное)
    - Email (уникальный)
    - Пароль (не менее 6 символов)
3. Нажмите "Зарегистрироваться"

### Вход в систему
1. Перейдите на `/login`
2. Введите email и пароль
3. Опционально: отметьте "Запомнить меня"
4. Нажмите "Войти"

### Доступные маршруты
#### Публичные (доступны всем)
- `GET /` - главная страница
- `GET /about` - о проекте
- `GET /search` - поиск мест
- `GET /login` - вход в систему
- `GET /register` - регистрация
#### Защищенные (только для авторизованных)
- `GET /profile` - профиль пользователя
- `GET /logout` - выход из системы
